화면 설명
1
드롭 영역
폴더째 끌어다 놓기. 한 번에 최대 500장. 변환은 관리자 PC 브라우저에서 진행되므로 창을 닫지 않도록 안내(닫으면 이어서 진행).
2
처리 대기열
파일별 변환 방식(내장 미리보기 / 전체 현상 / 파노라마)과 상태. 실패 파일만 모아 재시도. 같은 사진(해시 일치)은 "이미 올린 사진" 경고.
3
게시물 묶기
촬영 시각 간격으로 자동 분류, 드래그로 사진 이동 · 묶음 분리/합치기, 대표 사진 지정. 묶음 하나가 게시물 하나.
4
일괄 적용
선택한 묶음 전체에 카테고리 · 작품 · 행사 · 장소를 한 번에. 개별 수정도 가능.
5
크레딧
회원이면 승인 요청 발송, 미가입자는 외부 링크로 기록 → 가입 후 크레딧 소유 요청으로 연결.
6
촬영 동의 기록
1단계 초상권 보호 장치. 인물 사진(코스프레 · 모델)은 기록이 없으면 게시 불가. 첨부 파일은 비공개 버킷에 저장, 열람 시 감사 로그. 미성년자 체크 시 보호자 동의 필수 + '노출 주의' 비활성.
7
등급 · 공개
회원 업로드(S-08)와 같은 규칙.
8
게시 방식
즉시 · 예약 · 임시저장. 예약 게시물은 A-03에서 일정 확인 · 변경.
