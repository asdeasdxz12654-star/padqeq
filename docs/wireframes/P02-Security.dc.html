1
엣지 (Cloudflare 무료)

2
인증
카카오 · Google 소셜 로그인 기본. 관리자 2단계 인증 필수 + 관리 화면은 Cloudflare Access 뒤. httpOnly 쿠키, 갱신 토큰 교체, 새 기기 로그인 알림, 민감 작업 재인증
3
앱 서버 (Workers)
서버 액션 = 공개 API로 취급: 입력 검증(Zod) → 로그인 → 권한. nonce 기반 CSP, frame-ancestors none, SameSite 쿠키, Turnstile 서버 검증
4
데이터
모든 테이블 RLS 기본 거부, secret 키는 서버에만(새 publishable/secret 키 체계), 권한 테스트 자동화, 저장소 비공개, 최소 수집
5
감시 · 대응

공급망 · 패치
pnpm: 설치 스크립트 차단 + 새로 배포된 패키지 설치 보류. Dependabot, GitHub 비밀키 유출 차단, Actions 커밋 해시 고정, OIDC 배포. Next.js · React 보안 공지는 48시간 안에 적용.
