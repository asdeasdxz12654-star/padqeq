화면 설명
1
검색 · 상태
제목 · ID · 업로더 · 태그 통합 검색. 상태별 칩: 게시됨 · 예약 · 임시저장 · 숨김 · 검수 대기.
2
연도 칩 · 필터
회원 사이트와 같은 촬영 연도 칩(자동 생성). 카테고리 · 등급 · 신고 1건 이상 · 동의 기록 없음 필터. 표 / 썸네일 보기 전환.
3
일괄 작업
선택하면 나타나는 작업 바. 실행 전 "N개에 적용합니다" 재확인. 삭제는 휴지통으로(30일 복구).
4
목록
50개 단위 페이지, 열 정렬. 신고 있는 게시물은 빨간 숫자. 예약 게시물은 날짜 표시.
5
상세 패널
행을 누르면 오른쪽에 열림. 목록 위치를 잃지 않음. J · K로 위아래 게시물 이동.
6
조치
숨김(즉시 비공개, 복구 가능) · 등급 변경(업로더 알림) · 오늘의 픽 지정(날짜 선택) · 정보 수정 · 삭제(사유 입력).
7
촬영 동의 기록
파일 열람 시 사유 입력 + 감사 로그. 기록이 없는 인물 사진은 목록에서 경고.
8
이력
업로드 · 게시 · 수정 · 등급 변경 · 신고 · 검수 · 크레딧 승인을 시간순으로.
+
휴지통
같은 표 구조에 '영구 삭제 예정일' 열. 복구 · 즉시 영구 삭제(재인증 + 사유).
