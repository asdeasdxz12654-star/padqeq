화면 설명
1
운영 단계 전환
1인 운영 → 초대 회원 → 일반 개방. 단계에 따라 메뉴 · 권한 · 크레딧 방식이 자동으로 바뀜. 전환 전 체크리스트 + 재인증.
2
긴급 스위치
공격 · 장애 시 가입 · 업로드 · 댓글을 즉시 중단하거나 읽기 전용 모드로. 회원 사이트에 안내 배너 자동 표시.
3
속도 제한 · 한도
P-02의 기준값을 코드 수정 없이 조정. 변경 이력은 감사 로그.
4
회원 기본 정보
개인정보는 마스킹, 원문은 사유 입력 후 열람(기록). 성인 인증은 결과만.
5
이력
가입 경로(초대 코드), 인증, 제재, 신고 이력을 시간순.
6
조치
제재 단계: 경고 → 업로드 정지 → 기간 정지 → 영구 정지. 조치마다 사유 필수, 회원에게 알림 + 이의 제기 링크.
+
다른 시스템 탭
저장소 · 비용(회원별 사용량), 무료 한도, 처리 대기열(재처리), 보안 이벤트(로그인 실패 · 열람 속도 초과 · 차단 봇), 백업(DB 내보내기 결과 · 외장하드 백업 기록 · 복구 훈련), 금칙어, 관리자 계정(생성 · 역할 · 2단계 인증 초기화 · 세션 종료), 감사 로그(검색 · 수정 불가).
