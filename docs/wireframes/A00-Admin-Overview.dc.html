UI 원칙
데스크톱 중심 — 왼쪽 메뉴 · 상단 전체 검색 · 표 + 오른쪽 상세 패널
모바일은 긴급 업무만 — 대시보드, 신고 처리, 읽기 전용 스위치
실수 방지 — 위험 작업은 빨간 버튼 + 확인 문구 직접 입력, 일괄 작업은 대상 수 재확인
환경 표시 — 상단에 "운영" / "테스트" 배지 상시 표시
단축키 — / 검색, J · K 이동, A 승인, R 반려, ? 도움말
연도 칩 — 게시물 · 통계 화면에서 회원 사이트와 같은 촬영 연도 칩
관리자가 회원 사이트에서
관리자로 로그인한 상태에서 게시물 상세를 열면 상단에 관리자 바(숨김 · 등급 변경 · 오늘의 픽 · 이력 · 촬영 동의 기록)가 나타납니다. 관리자 바의 조치도 감사 로그에 남습니다.
