공통 규칙
내비게이션모바일: 하단 탭 5개(홈·탐색·업로드·커뮤니티·마이). 데스크톱: 상단 GNB + 우측 업로드 버튼. 같은 탭을 다시 누르면 맨 위로 이동합니다.
브레이크포인트~767px 모바일(피드 2열) · 768~1199px 태블릿(3열) · 1200px~ 데스크톱(4~5열 + 우측 레일)
테마다크 모드 기본, 라이트 모드 지원. 무채색 UI에 포인트 컬러 1개(좋아요·주요 버튼)만 사용합니다. 와이어프레임은 가독성을 위해 라이트로 그렸습니다.
이미지원본 비율 유지, AVIF 변환본만 서빙(긴 변 4000px, 파노라마 예외), EXIF GPS 항상 제거, 다운로드 기능 없음.
광고·구독 없음어떤 화면에도 광고 슬롯이나 유료 등급을 두지 않습니다. 모든 기능은 모든 회원에게 동일하게 제공합니다.
접근성터치 영역 44px 이상, 업로드 시 대체 텍스트 입력란 제공, 대비 4.5:1 이상.
표기 범례1와이어프레임의 번호는 오른쪽 설명 패널의 같은 번호 항목과 대응합니다.회색 상자는 이미지·영상 자리입니다.
