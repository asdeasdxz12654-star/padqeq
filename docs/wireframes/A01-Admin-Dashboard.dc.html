OTP 6자리, 붙여넣기 지원. 복구 코드는 1회용. 성공 시 새 기기면 다른 관리자 · 이메일로 알림.

누르면 해당 목록으로 이동. 최우선 신고(미성년자 · 초상권 · 도촬)가 있으면 빨간 테두리.
