RAW: CR2 · CR3 · NEF · ARW · RAF · RW2 · ORF · DNG. 회원 브라우저에서 LibRaw(WebAssembly)로 해석하고 RAW 파일은 서버로 보내지 않습니다. 내장 미리보기가 2560px 이상이면 그것을, 작으면 전체 현상. 모바일은 내장 미리보기만. 업로드 화면에 '보정 전 원본' 표시 후 확인 게시.

파노라마 (가로세로 2.5:1 초과) 짧은 변 ≤ 2000px, 긴 변 ≤ 16000px, 장당 6~8MB. 피드는 2:1 가운데 자르기 + '파노라마' 배지, 상세는 좌우 이동 뷰어.
서버 거부 기준 마스터 8MB(파노라마 12MB) 초과, 위 해상도 규칙 위반, GPS 잔존, SVG · HTML.
4000px보다 작은 사진은 키우지 않습니다. 무손실 원본은 서버에 두지 않음(운영자 외장하드 · 회원 각자 보관).
저장 구조 · 데이터 흐름
1
회원 브라우저 — 형식 확인, RAW 해석, AVIF 변환, GPS 제거, 변환본 4종 + 구형 기기용 JPEG 생성
2
업로드 주소 발급 (Workers) — 로그인 · 업로드 한도 확인 후 5분 만료 · 용량 고정 서명 URL
3
R2 저장 — 공개 주소 없는 버킷. 경로는 무작위 UUID
display/{미디어ID}/{w4000|w2560|w1200|w400}.avif · w1600.jpg
4
서버 검증 (Workers) — 파일 내부 구조 · 해상도 · 용량 · GPS 재확인, 실패 시 삭제 후 거부
5
DB 기록 (Supabase) — 게시물 · 미디어 메타데이터, 상태: 업로드 중 → 게시됨
6
보기 (이미지 게이트) — 세션 · 속도 확인 후 서명 URL. 캐시는 파일 경로 기준이라 보안과 속도 동시 확보
백업 · 삭제 · 보관
